# YusufSpoofer

Jailbreak tweak that spoofs the visible iOS version for selected apps or App Store.

## Features
- App Store spoofing mode
- Global or selected bundle mode
- Simple Preferences bundle entry for toggling values
- Confirm action to apply the selected version and reload the app state

## Default values
- Enabled: YES
- Major: 17
- Minor: 7
- Patch: 0
- Mode: appstore

## Usage
1. Install the tweak package.
2. Open Settings and find YusufSpoofer.
3. Pick the version and tap Confirm.
4. Respring if prompted to apply the spoofed version.
